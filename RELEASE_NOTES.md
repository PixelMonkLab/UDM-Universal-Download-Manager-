## UDM – Universal **Download** Manager · v1.1.0 Beta

### 🆕 What's new in 1.1.0
- **A real desktop app for Windows and Mac.** UDM now has its own native window, so you no longer need a browser tab. No Python needed on Mac any more either.
- **Keeps downloading when you close the window.** UDM stays in the tray (Windows) or the menu bar (Mac).
- **Quitting pauses your downloads**, and they **continue by themselves** the next time you open UDM. Downloads you stopped yourself stay stopped.
- **Refresh download address, like IDM.** When a download link expires, UDM asks for a fresh one by itself: open the download page and click the link again, or paste the new link. UDM continues from where it stopped and checks that it's the same file.
- **Start UDM when I log in** (Options → App), and Windows / Mac notifications when downloads start and finish.
- **The browser add-on opens the UDM window** instead of a browser tab when the desktop app is running.
- UDM's own code is compiled to machine code in the app.
- **To update:** quit the old UDM, then replace it with the new download. In your browser's extensions page, click **↻ Reload** on UDM.

### ⬇ Which file do I need?
| You have | Download | Then |
|---|---|---|
| **Windows** | **UDM-Windows.zip** | Unzip → open the UDM folder → double-click **UDM.exe**. |
| **Mac with Apple Silicon** (M1, M2, M3, M4…) | **UDM-Mac-AppleSilicon.zip** | Unzip → drag **UDM** to Applications → right-click it → **Open** (first time only). |
| **Mac with Intel** | **UDM-Mac-Intel.zip** | Same as above. |
| **Linux** (or any computer with Python) | **UDM-Linux.zip** | Unzip → run `bash start-mac-linux.sh` (browser version). |
| Browser add-on (Chrome, Edge, Brave, Opera) | **UDM-addon-chrome-manual.zip** | Easiest: in UDM click **🧩 Browser add-on** |
| Browser add-on (Firefox) | **UDM-addon-firefox.zip** | In UDM click **🧩 Browser add-on** |

_Store packages (`UDM-addon-edge.zip`, `UDM-addon-chrome-store.zip`) are for publishing to the add-on stores._

### What's inside
- 🎬 **Video downloader:** YouTube, Instagram, Pinterest and streamed (blob) videos, up to 4K, MP3, trim, subtitles, batch.
- 🖥 **Desktop app:** native window, tray / menu bar, pauses on quit and continues on the next start.
- 🗂 **Download manager like IDM:** any file, several connections at once, pause and resume (even after a restart), queue, speed limit, categories.
- 🧩 **Browser add-on:** a Download button on the page, docks in the side panel, notifications, takes over browser downloads.
- 📱 **Phone:** scan a QR code and download on your phone through your computer (same Wi-Fi).

**Windows:** the first time, Windows may say "Windows protected your PC". Click **More info → Run anyway**.
**Mac:** the first time, right-click UDM → **Open**. If macOS says it can't verify UDM, click **Done** (not Move to Trash) and see HOW TO USE - Mac.txt.

Only download content you own or have permission to save.
